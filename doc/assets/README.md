## 최신 정리 라운드 — 월간 홈

사용자는 1차 시안 중 두 번째의 월간 레이아웃을 선택하고 다음을 고정했다: 기간 바 양 끝에 날짜/시각만 표시, 진행 영역의 체크박스 제거, 시작 예정/카운트다운 중복 제거, 단일 추가 진입점, 앱명·검색 헤더 삭제, 중앙 정렬 아이콘 전용 하단 내비게이션, 카드/칸 테두리 없이 여백으로 구분. 세 방향은 이 요구를 공통으로 유지한다. 최신 정리 라운드에서는 1번 「경계 없는 월간」을 최종 선택했고, 배경은 순백색으로 바꾸고 라벤더는 포인트 색으로만 사용한다. 이후 사용자가 Figma를 직접 다듬은 버전을 최신 시각 기준으로 삼고, 홈 상단에는 임박 기간 최대 세 개를 보여주며 초과분은 캘린더를 가리지 않고 아래를 덮는 3열 오버레이로 연다.

| 표시 순서 | 방향 | 파일 | 목표/실제 크기 | 상태 |
|---|---|---|---|---|
| 1 | 경계 없는 월간 | [PNG](concepts/home-month-borderless.png) | 1440×1024 / 1487×1058 | 선택됨 · Figma 화면 기준 |
| 2 | 한 줄 타임라인 | [PNG](concepts/home-month-timeline.png) | 1440×1024 / 1487×1058 | 미선택 |
| 3 | 캘린더 우선 캔버스 | [PNG](concepts/home-month-calendar-priority.png) | 1440×1024 / 1487×1058 | 미선택 |

수정된 화면은 앱명 없이 기간 행과 월 이동 제목부터 시작한다. 상단 기간은 최대 세 개를 정적으로 보여주며, 더 있으면 기존 세 개를 포함한 전체 목록을 3열 오버레이로 연다. 하단 홈/캘린더 아이콘은 보이는 레이블 없이 중앙 정렬한다. 보조기술용 레이블은 구현 요구로 유지한다. 월간 날짜는 7열 날짜 정렬과 일정 점만 사용하며 상자 테두리를 그리지 않는다. `/calendar`는 TodoMate처럼 날짜 중심으로 탐색하고 시간 블록 표를 사용하지 않는다.

세 장은 각각 별도 Image Gen 결과다. 1번은 첫 정리 시도의 중복 텍스트·날짜 칸 선을 제거한 편집 결과이며, 이 원본 탐색 시안은 당시 TodoMate 월간 캡처와 라벤더 팔레트 시안을 참고해 생성했다. 2·3번 생성 호출에는 정리된 방향 이미지와 TodoMate 월간 캡처, 팔레트 시안을 직접 첨부했다. 1440×1024로 요청했으며 원본 결과는 모두 1487×1058이다.

선택한 구조를 Figma에 데스크톱 1440×1024와 iOS 390×844 프레임으로 제작했다: [데스크톱 홈](https://www.figma.com/design/o81oyODBLYZuzBAkKcWqgp?node-id=7-4) · [iOS 홈](https://www.figma.com/design/o81oyODBLYZuzBAkKcWqgp?node-id=7-247). 모바일 PNG 생성물은 없으며, 이전 세트 이미지와 생성 프롬프트는 보존한다.

## 시각 검토와 알려진 한계

- 예시 기준은 2026-10-03 토요일 09:40, Asia/Seoul이다. 09:48 시작까지 08:00, 9/19 18:00부터 10/9 18:00까지 약 68% 경과, 하위 할 일 3개 중 2개 남음이다.
- 보관된 1차 월간 시안에는 진행 퍼센트·남은 일수 중복 문구와 기간 체크박스가 남아 있다. 최신 정리 라운드에서는 해당 요소를 제거했으며, 최신 이미지가 기능 계약을 대신하지 않는다.
- 생성 이미지의 바 길이, 글자, 날짜가 기준 계산과 다를 수 있다. 계산·상태의 기준은 문서 02/04/05/06이다.
- 충돌·오류·오프라인·가져오기 화면은 화면 이미지에 없더라도 제품 요구사항으로 유지한다.
- 프롬프트와 실행 결과 기록은 [시안 생성 프롬프트](generation-prompts.md)에 있다. 시안 생성에 사용한 Image Gen은 Luna 문서 에이전트와 다른 도구다.
