# TodoList macOS v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Recompose Todo into the supplied macOS v4 Today, Progress, Calendar, inspector, and Settings experience while retaining existing data and sync behavior.

**Architecture:** Keep `CalendarItem` and `Repository` as the canonical model/write boundary. Build focused route components and reusable selection/detail UI around current projections, editors, preferences, local preview store, and sync state; keep additions to the record shape optional and backwards compatible.

**Tech Stack:** Next.js 16.3.8 App Router, React 19.3.0, TypeScript 5.9.3, CSS Modules, Supabase, Vitest, Playwright.

**Spec:** `doc/superpowers/specs/2026-10-23-macos-v4-design.md`

## Global Constraints

- Keep the current Next.js, React, TypeScript, and Supabase stack.
- All database operations go through `src/lib/repository.ts`; raw SQL is prohibited.
- New client components start with `'use client'`.
- Use TypeScript, two-space indentation, semicolons, and no `any` or production `console.log`.
- Do not add a production dependency without a documented `[ASSUMPTION]` and PR discussion.
- Do not remove or reset existing records, auth, sync, local preview, backup, recurrence, or settings.
- Do not use TDD or write implementation steps that depend on seeing a test fail first.

## Review Focus

- Missing or deleted `linkedTaskId` target: keep the saved checklist fallback and avoid dropping either record.
- Repeating event across a week boundary or its `untilDate`: render only valid occurrences and keep the existing recurrence semantics.
- Month/year cells with more entries than fit: preserve access through a counted overflow action and the day inspector.
- Imported malformed, legacy, or duplicate-ID local backup: reject before the first write and leave current records unchanged.
- At 1024×768 and with long Korean titles: keep controls reachable without horizontal clipping or hidden actions.
